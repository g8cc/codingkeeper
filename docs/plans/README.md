# 执行计划与交接

跨模块、跨会话或需要多轮验证的工作使用仓库内计划，避免任务只存在于聊天上下文。小改动直接在变更说明中记录即可。当前导航见 [文档总览](../README.md)。

计划文件使用 `YYYY-MM-DD-topic.md`，从 [模板](TEMPLATE.md) 开始，明确用户结果、范围、硬约束、步骤、测试与证据。状态使用进行中 / 已完成 / 阻塞；只有实际验证完成才能写已完成。阻塞项注明缺什么、可独立继续什么以及下一步。

续接时先核对物理 cwd、origin、Git 状态，再读计划、相关实现和最近验证记录。保留已有工作；不要根据旧计划重新创建退役目录。历史执行结果不能自动复用于变化后的源码。
